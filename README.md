# angular-study

This repository contains small Angular projects and exercises.

## Current project

- `directives-playground/`: Angular CLI app used to learn about directives.

## Run the app

```bash
cd directives-playground
npm start
```

## Next steps (directives)

Some useful CLI commands while learning directives:

```bash
cd directives-playground

# Attribute directive
ng generate directive directives/highlight

# Structural directive
ng generate directive directives/if-authorized
```
